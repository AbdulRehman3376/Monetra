# MONETRA

Simple student food-budget planner. Works fully offline, all data is saved on the device.

## Screens
- **Home**: money left, daily target, monthly spending graph, today's meals
- **Budget**: starting budget, essentials, added funds, savings goals, CSV export, 9 PM reminder
- **Diary**: calendar, meals and other expenses per day, monthly graph

## Run in a browser
Open `frontend/public/index.html`.

## Android (Capacitor)
```
npm install
npx cap sync android
npx cap open android
```
